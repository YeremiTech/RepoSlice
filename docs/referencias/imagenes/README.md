# Imágenes de referencia

Guarda aquí imágenes que sirvan como referencia visual para futuras mejoras de RepoSlice. Se aceptan formatos PNG, JPG y WebP. Usa nombres breves y descriptivos, por ejemplo `resumen-desktop.png` o `filtros-endpoints.webp`.

Al enlazar una imagen desde el README raíz, usa una ruta relativa como:

```markdown
![Referencia de la vista Resumen](docs/referencias/imagenes/resumen-desktop.png)
```

Indica en el texto que acompaña la imagen si es una referencia de diseño o una captura de una versión publicada. No incluyas credenciales, datos privados ni capturas de repositorios con información sensible.
